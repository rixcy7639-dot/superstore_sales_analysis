# Superstore Sales Analysis - 2.26M Dashboard
By Rixcy | MySQL + Power BI Project

## Project Overview
Analyzed Superstore sales data to find insights on sales performance by Category, Region and Ship Mode.

## What I Did
1. Created MySQL Database: `superstore_db`
2. Imported 145+ orders from CSV to MySQL table `superstore`
3. Wrote SQL queries:
   - Total Sales, Total Orders
   - Sales by Category, Region, Ship Mode
4. Built Power BI Dashboard (2.26M total sales)

## Dashboard Visuals
- Sales by Ship Mode (Bar chart)
- Sales by Region (Donut chart)  
- Sales by Category (Column chart)
- KPI Cards & Region Slicer

## Tools Used
MySQL Workbench, Power BI Desktop, Canva, GitHub
